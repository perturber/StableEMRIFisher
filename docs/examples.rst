Examples
========

The example notebooks of the `examples folder <https://github.com/perturber/StableEMRIFisher/tree/main/examples>`_, shown with their stored outputs. To run them yourself, clone the repository and open them from ``examples/``; run the :doc:`tests <installation>` first. Start with the :doc:`examples/quick_start_tutorial`.

The script that computes the Fisher matrix compared with an MCMC posterior is shown on the :doc:`validation/validation` page.
